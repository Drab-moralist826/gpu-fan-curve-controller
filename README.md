## Features

- Custom fan curve with up to 8 temperature-speed control points
- Supports NVIDIA (NVAPI) and AMD (ADL) discrete GPUs
- Applies on Windows startup automatically
- Real-time GPU temperature graph
- Emergency override hotkey: forces 100% fan speed instantly

## FAQ

**Do I need MSI Afterburner installed?**  
No. This tool communicates directly with the GPU driver APIs.

**Will it work on a laptop GPU?**  
Laptop GPUs often have locked fan controls - results vary by manufacturer and model.

## Requirements

- Windows 10 / 11 (64-bit)
- Windows 10 or 11, NVIDIA or AMD discrete GPU
